# Choosing a Hexagon deposit after the proof cleanup

The 17-page **Holomorphic source asymptotics and volume limits for strict
Conway compositions** is the lead article for the volume result. It now
contains only its pure-source proof. The volume reference shares those
proof files and supplies the conceptual account and independent volume
families. Its final page count is recorded by the build, not fixed here.

The application uses named companion results. Fix accessible editions of
the Newton calculus, whole-source bounds, finite spectral evaluation,
oscillatory fillings and marked strict geometry. The geometry paper also
uses the general marked-filling paper. These seven current PDFs total
149 pages; that is the declared dependency closure, not a claim that the
17-page paper is standalone.

For a smaller first deposit, the 11-page **Oscillatory filling sums with
independently long twists** isolates the whole-sum noncancellation
theorem under explicit source hypotheses. It does not by itself establish
those hypotheses for the knot family.

The [current formalization](../formal-real/README.md) proves the
synthesis Gram form, shifted Parseval, full Hermite coefficient mass
bound and complex bilinear Schur block algebra.
[ConwayAssembly](../formal-real/ConwayAssembly.lean) derives the
whole-color error bound from the actual crossing coefficients;
[RealTransfer](../formal-real/RealTransfer.lean) then proves eventual
nonvanishing and the ordinary logarithmic limit from the complex packet
and strict remainder gap. Source contours, the nonzero packet and the
marked geometric equality remain explicit written inputs. A separate
pinned source package and the exact [coverage map](../formal/coverage.json)
should accompany a link from the article.

[Hexagon](https://hexagonmath.org/about) accepts TeX deposits and links to
separately hosted formalizations; Lean code is not part of the submission
itself. It provides moderation,
[not peer review](https://hexagonmath.org/who).

Any eventual source package should use an explicit public-file list.
No remote draft or submission has been made.

The [cleanup record](PROOF_PATH_CLEANUP_2026-11-25.md) identifies the
current manuscripts and replay.
