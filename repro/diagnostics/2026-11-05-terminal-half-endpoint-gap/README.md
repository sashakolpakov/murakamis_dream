# Terminal half-point action diagnostic

This is a floating diagnostic, not a uniform inequality or a source theorem.
It reuses the 50 archived original endpoint proposals whose external leg lies
in the already admitted coherent source height bands. It solves no new
endpoint map and performs no optimization. The only additional row proposal
is the explicit quadratic/cubic cotangent root at the terminal half point;
its original logarithmic residual is reported, not interval-certified.

With the original endpoint functions and logarithmic lifts, it evaluates
the real difference between

\[
 Q_\epsilon(t;a,e)-g(a)-(1+\epsilon)g(e)+J(e)+S(e)
\]

at the archived joint critical point and at
\(e=1/2\), \(t=s_*(a,1/2)\),
\(u=1/4+i\log(3)/(4\pi)\). Thus the terminal Fourier allocation is
retained. The factor on the other side of the unchanged leg is common
and cancels. This is not a comparison after moving that leg, nor a bound
for the wider open-reference heights outside the coherent packet domain.

The input and driver are hashed in `result.json`. Run from any directory:

    python3 repro/diagnostics/2026-11-05-terminal-half-endpoint-gap/diagnose.py

The archive also keeps four raw-versus-coherent comparisons, one at each
already saved disk center. A bounded scalar bisection is used only for
these four real-row optima. It is floating arithmetic and is not the
outward raw-gap certificate. No endpoint solve or parameter optimization
is added.
