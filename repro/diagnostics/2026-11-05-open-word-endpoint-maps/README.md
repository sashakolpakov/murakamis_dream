# Bounded open-word endpoint proposals

This archive contains 132 floating endpoint-map proposals: the centers
and two sets of 16 equally spaced circle points in each of four typed
external disks. It also contains two symmetric one-vertex proposals.
There is no optimizer, interval cover, or finite-source conclusion here.
The result records the script and input proof hashes.

The equations are the original logarithmic gradient equations with
the ordinary endpoint variable retained. The endpoint private leg and
auxiliary variable are distinct from the attached leg seen by the next
vertex. The proposed images lie inside the specified private/auxiliary
rectangles and the attached leg's own typed disk.

These proposals have subsequently been superseded as proof by
[the complete four-disk theorem](../../../notes/research_mixed_open_word_critical_localization.md)
and its author256/saved320 records: 5,258 accepted cells, 233 excluded
rectangles, 10,978 exact tree nodes, and two one-vertex disks. The
diagnostic is preserved separately and remains explicitly non-rigorous.
Neither the diagnostic nor that critical-geometry theorem supplies the
ordinary endpoint finite-source packet on its complex image.

Run from the repository root:

```sh
python3 repro/diagnostics/2026-11-05-open-word-endpoint-maps/diagnose.py
```
