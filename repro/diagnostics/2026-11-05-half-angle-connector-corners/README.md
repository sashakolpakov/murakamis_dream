# Half-angle connector corner diagnostic

Bounded diagnostic, 5 November 2026. These files preserve the original script,
result and log byte-for-byte. The script uses the fixed workspace path recorded
in its source and writes its result to `/tmp`; no source artifact is changed.

The pilot evaluates the 16 distinct external rectangle corner pairs for each
of 32 five-window type words and four external type pairs: 2,048 points total.
Each point uses the original outward Newton branch and phase enclosure. The
minimum reserve is approximately 0.129143975, for central types (4,3,4),
window (4,4,3,4,3), external references .27-.02i and .39+.02i. Replacing
the typed collar by the common ceiling 1/50 still leaves about 0.122670027.

The expression is Re Gamma_pair(.5,.5) minus the exact half-angle source
constants, the typed collar, and rotated real-displacement costs
5.5(.5-Re a)^2+7.55(.5-Re c)^2. It retains the literal chirped allocation
and contains no additional Q debit.

This is not a distinguished-boundary cover or a uniform theorem. No
optimizer is used. It motivated the separate complete new certificate;
only that certificate can establish a uniform reserve.
