Adjacent product junctions in the main-meridian source bound

This special-case argument is retained in full. The general component theorem and filled-meridian theorem now permit every fixed strict bare component, without an additional valence or path condition.

1 November 2026.

The main-meridian source bound allows a product junction with no crossing-circle operator only when the neighboring product junctions carry such operators. This note gives a sufficient condition that permits several junctions without an operator to be adjacent. The condition counts the branches attached to each connected group of these junctions. More attached branches provide a quantitative margin that controls the error introduced by the next turn.

The comparison uses the positive complete-color calculation for the same tangle construction. Every boundary variable remains constrained by its original product and closing equations. In particular, the proof retains the additive constants in the boundary profiles; independently optimized pieces are not assigned a common boundary value after the fact.

The result applies to a fixed finite tree. It includes a bound on the summed contribution of high Newton indices, which is needed when the crossing-circle operators are replaced by fixed crossing powers. That bound remains a comparison with the augmented action. A theorem for the smaller filled-knot exponent requires the additional contour and stationary-phase analysis of the filled source.

1. The tree and the sufficient condition

Start with a strict ordered Conway construction in the sense of the general strict-tree theorem, Sections 1–3. Its leaves represent the prescribed rational pieces. 6. Grouped high-index errors and fixed crossing powers

The preceding norm estimate must be refined to distinguish inherited errors from newly created high indices. This distinction prevents an error from being charged another 2G02G_0 every time it crosses a flagged junction.

7. The source bound, geometric constants, and remaining scope

For the unfilled physical source (1), a flagged branch has fL(u)=g(u)+c,c=∑iΩi,ΩL=c+2G0. f_L(u)=g(u)+c,\qquad c=\sum_i\Omega_i, \qquad\Omega_L=c+2G_0. \tag{39} A bare branch retains fQ(u)=fA(1−u)f_Q(u)=f_A(1-u) and (18). The path condition is sufficient, not a classification of all adjacent bare components. The tree, colors’ roles, framing, and every fixed crossing power are fixed before the level tends to infinity. 8. Finite reproduction

The accompanying direct-crossing reproduction script compares powers of the full polynomial crossing, reduced modulo the physical relation, with the generic root-grid trace and the analytic complete first-normal trace. It includes negative powers and parameter values on both sides of the half-integer collision. A separate rational calculation checks the quadratic joint-charge comparison for unequal signed slopes. These finite checks do not prove the component pressure inequality or an asymptotic source theorem.

With Python and mpmath installed, run from the repository root:

python3 experiments/audit_main_meridian_direct_fillings.py

The default output is the reproduction record. Use --output to choose another location. The optional --profile-diagnostic flag repeats the archived local profile scan; it is numerical evidence and is kept separate from the finite identities and exact rational checks.
