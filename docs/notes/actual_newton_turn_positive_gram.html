A positive Newton metric for genuine original tangle turns

29 October 2026. The genuine quarter-turn of ANY original two-head Hopf box is a unitary reversal in an explicit full-dimensional Newton packet. Both original marked closures have dual norm ONE. Signed crossings have an explicit adjoint in this same metric, so a specified class of reflected rational/arborescent circuits is an exact positive norm of its coherent half-network. This is not positivity for an arbitrary fully augmented diagram, and no general sharp energy or new volume-equality class is inferred.
