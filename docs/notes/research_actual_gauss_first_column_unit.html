The actual Gauss first column as a zero-free analytic boundary kernel

18 November 2026. Private written proof.

This note estimates an initialized column of the actual operator ANA_N in [G], including its finite transfer sum, vacuum normalization and both factorial caps. The result is a full small-disk phase and nonzero amplitude. It supplies boundary data for a two-variable kernel problem; it does not estimate that entire kernel or its original closed source.

The quantum parameter and meridian are fixed at completeness. All occupations remain integers. The chamber is (T+1)/N(T+1)/N in a compact subset of (1/2,1)(1/2,1).
