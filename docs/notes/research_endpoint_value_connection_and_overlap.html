Endpoint connection constants and a finite-level bulk overlap

Private written proof, 16 November 2026.

The original microscopic endpoint values have explicit connection constants. Their derivation uses the terminating endpoint recurrence, an exact hypergeometric generating function, and a growing overlap with the original finite-level recurrence. No interchange of a fixed-index limit and a bulk limit is used.

The leading value oscillates in log⁡N\log N at nonzero real endpoint parameter. At parameter zero its two modes coalesce into a logarithm. The theorem supplies the value-derived part of the actual normal comparison; it does not identify a separately interpolated normal with that derivative.
