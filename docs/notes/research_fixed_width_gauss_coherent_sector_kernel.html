Actual fixed-width Gauss coherent kernels from reverse propagation

Private written proof, 18 November 2026.

The complete ordinary-binomial first row in B initializes reverse suffix-Casimir propagation. At the fixed root both apparent inverse Euler factors in the binomial-conjugated generators are exactly short clock-rotation integrals. This permits an analytic estimate of the actual low output coefficients, followed by recovery of the entire finite cap. The resulting full coherent kernel has a nonzero amplitude and a nondegenerate mixed phase on the specified small input sectors.

This proof does not transform the relative error of a monomial kernel. The input sum is paid first, and the new error estimate is propagated with its literal binomial weights.
