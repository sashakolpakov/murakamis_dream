Independent audit of the twisted source and balanced Weyl cocycle

Audit, 27 October 2026. The proof in twisted_cotangent_source_and_weyl_gluing.md passes this independent sign, scalar and endpoint check. No tests were rerun.

The cotangent transition is b′=w−w2b,w′=1/wb'=w-w^2b,\ w'=1/w, so dw′∧db′=dw∧dbdw'\wedge db'=dw\wedge db and −b′dw′=−bdw+dlog⁡w-b'dw'=-b\,dw+d\log w. The complete finite section formulas preserve O(N−1)O(N-1), and its reciprocal coordinate change gives precisely (K,E,F)↦(K−1,−F,−E)(K,E,F)\mapsto(K^{-1},-F,-E). The result is an explicit splitting, not a uniqueness assertion: norm-one gauge changes can give other rational splittings. Its zero/pole divisors and its nonconstant meridian germs remain part of the source lattice. The note correctly retains these data and does not infer generic coupon invariance, an arbitrary unipotent dressing, a geometric stationary coefficient, or the volume norm from the order-two gluing alone.
