An explicit half-degree Casimir polynomial for the original augmented pretzel base

Subsequent analytic theorem. This exact source now feeds the full coherent period asymptotic, which proves a nonzero leading coefficient and the actual augmented link volume rate at arbitrary fixed odd width. The formulas below retain their role as independently checked finite algebraic inputs.

29 October 2026. The COMPLETE mixed-circle base of every odd pretzel has a single, explicit pair-Casimir polynomial. Its degree is at most ⌊(N−1)/2⌋\lfloor(N-1)/2\rfloor. Its coefficients in the physical continuant basis are positive finite cosine/factorial products, with the actual half-twist phase retained. This yields all nodal values AND first normal jets, and an original one-variable coefficient source for every odd number of boxes. No geometric saddle or noncancellation theorem is inferred from this exact reduction.

2. Why the rotated box is a SINGLE full pair polynomial

An actual pair intertwiner rotates to another pair intertwiner by the Hopf cup and cap equations. Work first at generic nearby qq, with the ordinary finite highest module of dimension NN, its genuine dual turns, and the literal mixed-circle polynomial. These data specialize regularly to the displayed root source: all turn factorials have indices below NN.
