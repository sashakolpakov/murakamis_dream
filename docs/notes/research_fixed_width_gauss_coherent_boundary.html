Actual fixed-width Gauss coherent boundaries from the complete input sum

Private written proof, 18 November 2026.

The original ordinary-binomial input of the actual Gauss first row can be summed before taking any asymptotic limit. At every fixed width this gives two scalar coefficient integrals. Their original circles select a nonzero branch on a specified small input sector. The competing vacuum in the wider boundary is retained and estimated on the entire circle.

This is an actual coherent boundary theorem. It does not apply a binomial transform to an error estimate for a monomial kernel, and it does not yet propagate the coherent boundary to nonzero output activities. The smaller sector below is essential for the proof.

4. Actual coherent boundary and its normalization

In particular the original, unnormalized boundary is ⟨𝟎|AN(r)cT(z)⟩=a00(r)zrT(dT)N−peNΨ2πNℋAr∂(t*;C)AB(ξ/t*;τ)⋅(1+O(N−1)).(28) \boxed{\begin{split} \langle\mathbf0|A_N^{(r)}c_T(z)\rangle ={}&a_{00}^{(r)}z_r^T\binom dT\, N^{-p}\frac{e^{N\Psi}}{\sqrt{2\pi N\mathcal H}}\, A_r^\partial(t_*;C)A_B(\xi/t_*;\tau)\\ &\hspace{3.2cm}\cdot(1+O(N^{-1})). \end{split}} \qquad\text{(28)} Neither the width-dependent vacuum normalization nor the physical phases ci=xr−ic_i=x^{r-i}, nor the homogeneous character zrTz_r^T, nor the binomial factor has been omitted. The normalized action is calibrated by Ψ→0\Psi\to0 as a*→0a_*\to0, while (27) is only a punctured-sector asymptotic. The exact expression (8) remains valid in the microscopic region where this Gaussian approximation is not uniform.

The selected input sector is all-width and allows bounded complex shapes without requiring each ξi\xi_i to have a nonzero phase slope. Its proof used the full original input sum, not a termwise transform of the monomial approximation. This distinction is material: inactive Cauchy interfaces can create an extensive phase even when the corresponding monomial phase is constant.

The output in (28) is still the literal vacuum row. A theorem for nonzero output activities would need propagation of this coherent initializer with the exact binomial-conjugated input operators and their retained endpoints. No such propagation is asserted here. Nor does (28) estimate the exterior braid, turnover, inverse Cartan factor or closed source in the original opposite kernel. The proof is at fixed qN,M=1q_N,M=1 and physical integer TT; it gives no meridian normal, complex-degree interpolation or geometric-cycle coefficient.
