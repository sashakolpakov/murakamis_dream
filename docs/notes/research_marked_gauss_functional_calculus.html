Marked factorial calculus and the original Gauss source normalization

Private written proof, 18 November 2026.

The exact factorial ratio represents the actual finite Gauss operator on its prescribed physical logarithm germs, including endpoints, Casimir Jordan blocks, and the whole fixed-root meridian family. The marking matters. An individual integer logarithm shift can have a genuine radical meridian pole. A simultaneous shift of both logarithms is the scalar inverse cyclic Green multiplier, and changes the original sewn source if the other kernel is held fixed.

This is an exact definition and normalization result. It removes an ambiguity in replacing a finite polynomial by a special-function expression. It supplies neither a coherent propagation estimate nor a contribution of a geometric relative cycle.

For clarity, the actual local functional calculus is finite and unambiguous. On a fixed K0K_0-weight space, choose a small Riesz contour enclosing one root joint Casimir value and all the eigenvalues that split from it when MM varies. 3. Which channels are units, and which begin in the first normal

4. Exact logarithm decks and the cyclic Green scalar

5. The original closing source changes if a deck is dropped

The same scalar multiplication holds before integration in J’s three-kernel compact period. All occupation caps, factorial duals, Cartan twists, and meridian finite parts remain. 6. What is defined, and what is still not estimated

The original finite polynomial is now exactly represented by the factorial germs with labels 0,…,d0,\ldots,d, including every root endpoint and normal channel. This equality survives arbitrary ordered outer matrices and windows when the same primary resolution is retained. It does not identify a shifted logarithm germ with that same physical definition: (19)–(29) record the difference.

This establishes the marked local functional calculus, its unit and first-normal channels, and the concrete deck effect on the original source. No estimate of the primary projectors, their Fréchet normals, or the resulting coherent kernel has been supplied. In particular an analytic scalar logarithm is not an actual near-identity coherent evolution, and scalar nonvanishing in B is not a matrix norm estimate. Transporting these marked germs along a geometric contour still requires the actual logarithm transitions, endpoint channels, and relative-window currents. No intersection coefficient or knot noncancellation conclusion is asserted.
