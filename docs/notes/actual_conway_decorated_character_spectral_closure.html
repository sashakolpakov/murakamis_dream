Controlling a turn preceded by an actual character operator

A polynomial operator in a knot calculation is determined at a repeated spectral node by both its value and its first derivative. This note uses a norm retaining both pieces of data. It proves that a specific physical operation preserves useful bounds in that norm: multiply by the actual circle character and retained half twist, then apply the physical turn.

The result has three parts. The operation adds a precisely determined exponential cost, concentrates the canonical output polynomial near the spectral point −2-2, and gives a strict loss when any original circle color is a fixed fraction away from complete. Products preserve the same kind of estimate. Consequently one can iterate these operations through the recursive class defined in Section 4. The reduced-hub source adapter identifies that class with trees in which every multiplication hub has a distinguished original character.

A turn without such a character is a different operation. Its sharp norm cost is computed in Section 5, but this cost cannot simply be added to a previously fixed geometric action. The later positive-probe theorem supplies the additional estimate used for those regions in the full strict-tree proof.

The finite inputs are the original positive Newton turn and pairing, the full-Hermite localization estimates, and the exact root-character Fourier theorem. The rigid-spine geometry separately identifies the complete action for the fully flagged class.

In each case the original character remains immediately before its recorded turn. The proof is finite induction. Products use the exact norm product rule and multiply the actual polynomial envelopes. A decorated turn uses (10)–(11). The limitation of this particular induction is now explicit. It preserves a specified character multiplication immediately before each turn. An arbitrary internal turn with no such physical character is not charged to an existing original leaf by (20). Adding an artificial LjL_j, treating the turn as multiplicative, or assigning the resulting extra 2G02G_0 to the old geometric action would change the problem. Thus this lemma alone does not give the required geometric bound for a region without a character. The positive-probe and mixed-core propagation theorems treat that region separately; they are not consequences of pretending that (20) includes a bare turn.

The original alias identity converts (23) into a total nonempty-alias gap after a finite complementary-color expansion, with its exact scalar signs and source adapter retained. The local core packet and marked filling theorem are additional inputs. The strict-tree assembly combines these results with the separate estimate for regions without characters. This note proves the spectral closure lemma used there, rather than a filling theorem from the norm bound alone.
