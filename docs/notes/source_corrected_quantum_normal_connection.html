The actual source-corrected first quantum-normal connection

Independent construction and audit, 27 October 2026. The central freedom in the root regular profile is removed by a first quantum-normal lifting rule when the selected source has a nonzero kernel-to-cokernel symbol. The rule comes from the same whole finite-sum preoperator. It does not assume horizontality for the unsourced connection.

The nonzero-symbol hypothesis is essential and is not proved here for every actual knot operator. The result is a constructive uniqueness test for a specified source-normal comparison. It does not establish the regulator comparison, selected growth, or a global profile.

4. Central uniqueness and the essential symbol hypothesis

Suppose both vv and c(U)vc(U)v admit the same whole first-order lifting rule. By (1), (4), and (6), 0=∇act(cv)−c∇act(v)=Uc′(U)ι(v). 0=\nabla_{\mathrm{act}}(cv)-c\nabla_{\mathrm{act}}(v) =Uc'(U)\iota(v). \tag{7} If ι(v)≠0\iota(v)\ne0 in the generic descended cokernel, then c′=0c'=0, so c∈ℂc\in\mathbb C. A fixed nonzero ordinary-color anchor sets that constant to one. Constancy required no evaluation or regularity at the special central fiber U=1U=1.

Thus every nonconstant multiplier from the central profile freedom is excluded by the same actual source-normal rule when this hypothesis holds. A fixed source value for one section would not suffice: the crucial input is the linear rule RN(cv)=cRN(v)R_N(cv)=cR_N(v) from the same whole preoperator.

A semisimple eigenvalue one of T0NT_0^N makes ι\iota an isomorphism, so every nonzero section satisfies the hypothesis. The exact weaker condition is only ι(v)≠0\iota(v)\ne0. Neither condition has been established here for a general knot’s specified operator.

There is now a genuine all-knot witness in the canonical actual Mellin polarization: the observable quotient P^M Z/B supplies a dual monodromy row with value one on the selected section. It proves selected-symbol nonvanishing without either semisimplicity or a simple norm root. It does not transfer that statement to a different meridian regular-profile realization without its actual source map.

There is a directly checkable sufficient condition in the intrinsic quantum-A norm polynomial. Let H_0=T_0^N and

Delta_N(U,t)=det(tI-H_0).

This uses the intrinsic root norm of the specified quantum operator; it does not equate Delta_N with the classical A-polynomial. A rank jump or collision at U=1 does not by itself decide this generic condition; the marked lattice is still required at that special fiber.

The theorem proves a constructive restriction on pointed quantum comparisons; it does not prove that candidate knot periods are scalar multiples, that their compatible lift exists, or that their selected geometric regulator norms coincide.
