Exact height currents and local recentering of the polarized source

Private written proof, 16 November 2026.

Changing a frozen height in the contour-polarized family produces an explicit original endpoint current. It contains a sine of the charge offset and vanishes at unit charge. Its exponential majorant is the same one used for the original vertical current. Consequently nearby height tables in the certified small-charge region define sources that are exponentially equivalent, including all asymptotic coefficients. This is a local source transport statement; it supplies no new global boundary estimate along an arbitrary charge path.

3. Local exponential equivalence and recentering

Fix a same-index graph, base real powers 𝒃\mathbf b, complete outside angles, and a base small charge 𝝃∈(1/4000,1/2000)I\boldsymbol\xi\in(1/4000,1/2000)^I, as in the adopted pattern-adapted initializer.
