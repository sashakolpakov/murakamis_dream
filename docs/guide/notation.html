Three distinctions that matter

A generic normal versus a level asymptotic. A derivative in ζ=qexp⁡(t)\zeta=q\exp(t) keeps NN fixed and differentiates the genuine generic source. It is not the same operation as taking another term in a large-NN expansion.

A source normal versus a zero root value. A factor such as [2N][2N] vanishes at qq but has a nonzero derivative. Removing it before the prescribed normal is taken can change the invariant.

Complete versus filled volume. The augmented complement and a complement obtained by Dehn filling generally have different volumes. The filling theorem compares the deformed original source with the actual filled geometry, using its specified peripheral slopes.

The longitude variable LL in an A-polynomial, a complete-circle operator called LNL_N, and a recoupling coefficient denoted LG,EL_{G,E} are distinct objects. Likewise, a genuine turn and an inverse recoupling matrix can both be called RR in older notes. Consult their typed definitions before combining formulas.
