Research guide

Checking the formulas and reproducing the calculations

The repository contains written proofs, exact finite certificates, numerical checks and recorded outputs. They answer different questions. This chapter explains which calculations support which steps, and how to rerun them without treating a successful sample as a theorem.

An exact symbolic calculation can establish an identity in formal variables. A rigorously bounded interval calculation can establish an inequality over an entire stated parameter domain. A finite counterexample can disprove a proposed identity. By contrast, checking many quantum levels or plotting a growth rate does not prove a uniform limit as N→∞N\to\infty. The scope of each script must be read together with the mathematical argument that uses it.

The current strict Conway tree theorem includes bounds for the full quantum sum, a nonzero selected contribution, the original normalization and the actual marked filling geometry. Its proof is not waiting for a theorem about all knots. The more specialized general-plat calculations catalogued below retain their own hypotheses and limitations.

The quantitative short-twist estimate

The analytic criterion uses an explicit two-variable action on every edge and a uniform estimate for Newton polynomials on a complex strip. Its focused checks run with:

python3 repro/run_research_checks.py curvature-fillings

Python, SymPy and mpmath are required. The program verifies the wire critical equation, two derivatives of the selected action, and its Hessian determinant symbolically. It then checks 990 complex-strip samples at 70-digit precision, including even and odd levels from 160 to 256. The saved results also record the constants separating the first critical action from the discarded-state bounds. These samples check the formulas; the proof supplies their uniform validity. No test in this group certifies the topology or the hyperbolic volume of a short-filled knot.

Arbitrary multiplication regions

The general component theorem permits connected groups of product junctions of any fixed size and valence. Its new finite identities can be checked with one command:

python3 repro/run_research_checks.py general-components

The program constructs each Newton polynomial over an exact cyclotomic number field. It compares its Laurent coefficients with the formula in the Fourier reflection proof, and independently divides products by the deformed polynomial relation. Subtracting the complete trace must cancel the first Fourier term. A further calculation verifies fusion in the full quotient algebra, including inputs whose values at repeated roots vanish but whose derivative contributions remain nonzero.

The recorded results cover levels two through twelve, including both parities: 36 high-index polynomials, 721 trace differences and 33 fusion identities. These are exact finite algebra checks. The uniform Fourier loss, comparison of positive maxima and passage to the filled knot complement are proved in the three companion notes; the finite checks do not establish those analytical or geometric conclusions.

Trivalent multiplication regions

The component theorem has one reproduction command:

python3 repro/run_research_checks.py trivalent-components

The script constructs the Newton polynomials and performs division by the deformed polynomial relation in exact cyclotomic fields. It checks every cubic index triple through level ten, using symmetry to avoid repeated calculations. This includes internal indices above one half, zero and half endpoints, both parities, and the actual turn types. It also checks the elementary identities used in the simultaneous boundary comparison.

The script uses Python and SymPy and has no numerical approximations. It checks the finite algebra; the proof supplies the concavity argument, the uniform gap, and the complex estimates needed for the filled-knot theorem.

The preferred cusp correction

The exact crossing and framing calculation and the geometric longitude calculation can be reproduced together:

python3 repro/run_research_checks.py meridian-cusp

The scalar program composes signed crossing words and compatible typed products from their local formulas, retaining negative powers and both orders of opposite colors. It also checks the shifted-grid phase algebra. The geometric program verifies the rational meridian frames, the product and turn coordinate maps, the two half-twist signs, and the longitude correction under surgery. Python and SymPy are sufficient.

The scalar proof and longitude proof explain the global conclusions. The programs check their local identities; the identification of the preferred peripheral curves and the uniform large-level estimate are arguments in those proofs.

Running a named group

The research-check runner executes a selected group serially. The group manifest contains every command in its recorded order. Listing and previewing groups do not run a scientific calculation:

python3 repro/run_research_checks.py --list
python3 repro/run_research_checks.py general-plat --dry-run

To run one group, omit the dry-run option. The runner saves a separate combined output log for every command and a JSON summary containing exit codes and durations. It continues after a failed check so the summary records the whole selected group, then returns a nonzero exit code if any command failed. It does not run unselected groups. The individual scientific scripts keep their existing behavior, including any result files they normally write.

By default, logs go in a timestamped directory under the system temporary directory. To retain them in a chosen location, use:

python3 repro/run_research_checks.py pointed-a --log-dir /path/to/check-logs

The runner uses the Python interpreter that launched it. Select another interpreter with the --python option if the chosen group needs a different environment. The manifest replaces the former long command block; it preserves those commands rather than silently adding them to every build.

The moving-meridian filling calculation

The moving-meridian theorem has a focused reproduction group:

python3 repro/run_research_checks.py moving-meridian-fillings

It compares 380 finite evaluations at 80-digit precision. One calculation raises the full crossing polynomial to its signed integer power in the quotient algebra. The other uses the root-grid trace, including the derivative term at repeated roots. The cases include both level parities, negative crossing powers, and displaced complex meridians. A separate exact rational calculation checks 18 quadratic Fourier comparisons with signed twist numbers of different sizes.

The recorded output gives the precision and errors. These calculations test finite identities and normalization choices. The uniform contour estimates, the nonzero leading term and the identification with knot-complement volume are proved in the linked notes. The optional profile scan in the individual script is a numerical diagnostic, not a proof of the limit.

Where to start for the current theorem

The proof has three kinds of inputs. Exact source identities retain every color, repeated-node derivative and scalar factor. Analytical estimates control the large-NN limit uniformly on the domains used by the proof. Geometric constructions identify the cells, face maps, cusp markings and filling slopes of the actual complement. A finite algebra script can check an identity used in any of these arguments, but it cannot replace the uniform estimate or the topological construction.

The two-leaf block inequality and single-leaf attachment inequality have finite rational certificates. They bound the competing alias expressions over their whole slope domains. Their verification uses exact interval arithmetic, explicit remainder bounds and finitely many vertices of fixed polytopes. Candidate points may help find a certificate; the verifier proves the displayed inequalities without trusting an optimizer.

From the repository root, their principal verifiers are:

python3 repro/run_research_checks.py conway-certificates

The unflagged-region probe estimate applies those scalar inequalities to arbitrary coefficient arrays with the stated bounds. The spectral propagation proof then carries the estimates through turns and products, at the actual geometric action. These are written analytical arguments. They do not infer their conclusions from a longer list of sampled levels.

The general marked geometry follows the original diagram’s face pairings and primitive cusp paths. Its completeness and smooth-filling arguments are also mathematical proofs rather than numerical manifold recognition. The theorem uses the original literal diagram for topology even when a different algebraic expression is useful for an estimate.

Checks for the pointed quantum AA-period

The operator-period corollary combines the exact ADO annihilator and finite-pointing theorems with the already proved knot-volume limit. It does not estimate the invariant by replacing a signed companion-matrix product with its norm. Its constant-term formula is exactly the original scalar.

The relevant scripts are:

python3 repro/run_research_checks.py pointed-a

The first checks the generic finite crossing lift, finite-boundary identities and the repairs used when an elimination relation vanishes after summation or root specialization. The second checks moving-qq germs, including singular recurrence steps and their bounded derivative budgets. The third checks the coefficient ratio of the banded Gram determinants against the actual finite vector of color values. The general existence, uniqueness and asymptotic statements still rest on the corresponding proofs. The recorded outputs specify exactly which finite cases were run.

Installing dependencies and reading a result file

For the core symbolic and numerical scripts, install the recorded dependencies in a suitable Python environment:

python3 -m pip install -r requirements-core.txt

A result file’s scope field explains what a successful check means. Some scripts verify exact algebra; others compare an exact expression with an asymptotic approximation at selected parameters. Optional geometry checks may require SnapPy, Regina, Sage or packages named by that script. There is no claim that every historical diagnostic is one application-wide passing test suite.

The remainder is a topic-by-topic map of the earlier calculations. It retains their check counts and limitations so that a reader can reproduce an argument without confusing evidence for one formula with proof of a broader theorem.

Coefficient regions in the general-plat method

In this group of notes, a degree records how much of a face variable occurs in a polynomial coefficient. The labels CROSS, LEFT and RIGHT name regions of those degree inequalities; they are not new types of knot crossing. A protected variable is one fixed by the marked coefficient extraction. A seam is a boundary shared by two such degree regions. These definitions explain why a theorem on one region need not control the whole coefficient sum.

Sharp bounds and boundary arguments

The closed-domain upper theorem, full-fiber activation and stationary classification prove the corresponding boundary and stationary statements. Their arguments establish the directional entropy gains, free-spectrum retuning and protected cap exclusions directly. The odd main-strand cycle theorem uses exact source characters and original face demands; the flat-cap limitation is an exact alternating-sum inequality.

The seam theorem concerns the boundary between two degree regions of the original coefficient sum. Its moving cosine-log integral and pointwise tail comparison prove all-spectrum CROSS-degree domination; exact latent-triangle strong concavity gives the explicit gap γD=πaD2/2\gamma_D=\pi a_D^2/2. The existing whole-domain integration-by-parts theorem retains all charge currents and gives seam-period negligibility for fixed long fillings. These conclusions are analytical. For this general-plat route, the remaining macroscopic non-CROSS part is not controlled by the seam theorem alone.

The four-state and window audits below support the retained finite source factors and indices; they do not establish the analytic majorant, classify its maxima, or prove a global volume comparison. Each linked note states the domain and hypotheses of its proof.

Exact transfers supporting the phase estimate

The analytic phase argument has two focused finite checks:

python3 repro/run_research_checks.py phase-transfer

The four-state audit checks 196 recurrence/path comparisons and 85 exact omitted-half scalar identities across ten levels and both parities. The window audit checks 402 exact restricted matrix/path identities for half and full rows, including sampled spectral zeros and zero outer weights. Its equality is sign-adjusted on both sides; the common raw sign is established in the source proof.

These validate finite indexing and retained factors. The original physical-matrix interface is inherited from the stated original numerator formula. The positive transfer, analytic gauge, strict boundary gaps and shared-torus phase exclusion are proved analytically; these finite checks do not prove their exponential estimates or a global volume bound.

The protected-window and mixed-cycle extensions combine local transfer identities with a finite packing of graph cycles. The outer-zero proof specializes the exact transfer; the middle-zero proof retains the actual initial seed and proves its output reflection by finite tilings. The whole-CROSS input uses the central factorization and cofactor angular theorem. Fractional cycle packing is a finite combinatorial argument. Those consequences use no extrapolation of numerical rates; the stated global majorant comparison remains conditional.

A focused starting set

With the dependencies above installed, these four scripts are a smaller entry point into the local recoupling and positive variational calculations:

python3 repro/run_research_checks.py local-foundations

Read the corresponding result’s scope field before interpreting its reported outcome.

The arbitrary-plat advance has a separate focused set:

python3 repro/run_research_checks.py general-plat

The root, complex-action and amplitude notes contain their analytical proofs; root finding and large-level comparisons are regressions. The magnetic audit also tests the original finite Casimir equation and the exact joint rational formula, retaining the difference between Gaussian and positive sine binomials. The character and regulator audits check exact rational identities in formal variables. The marked gluing audit uses an actual three-cusp triangulation; the critical-scheme audit checks local inverses and 24 incidence graphs. The reflection and graph audits replay actual finite sources. None of these checks proves the missing general global asymptotic.

The joint determinant audit checks the source polynomial before continuation, its three-term recurrence and positive principal minors. The joint amplitude audit compares the literal finite sum with its determinant and asymptotic, including both derivative corrections at folded channels. The framing audit verifies the stated equivalences and local construction; it does not search for or prove a favorable common frame for every plat.

The generic-normal audits compare the original generic columns and derivatives, including the exact large-partner collision tail and nonzero extra-pole residues. The right-angled obstruction audit checks reflection signs, polarization identities and exact two-facet examples. Its general conclusion rests on the separate proof of the literal Morse-prefix dictionary and convex incidence, not on extrapolating those examples.

The exceptional-period checks

The matching-edge contour method has focused audits for the generic Casimir polynomial, its root location and positive endpoint convolution, the actual inverse-turn character relation, and the full resolvent with its normal poles. The strict-prefix and Green-action audits check original matrix entries and selected logarithms. The rectangle audit verifies the actual primitive words for all three half-twist cases. Each note links its script and recorded output.

The endpoint resolvent proof uses a unitary congruence and exact Schur denominator; it does not claim a Hermitian similarity or a polynomial bound for individual spectral projectors. Numerical rate samples supplement the written asymptotic proofs. None of these local or endpoint checks establishes a contributing contour or the general source asymptotic.

Rebuilding this guide and its figures

The guide is generated from book/chapters/ and the published notes. Its static HTML uses native MathML and local CSS and JavaScript; reading it requires no account or external math service.

python3 tools/build_book.py
python3 tools/check_book.py
python3 -m http.server 8000 --directory docs

The build requires Pandoc. TikZ sources and their compiled PNG/PDF figures are retained in book/figures/. To regenerate the figures, install a TeX distribution with TikZ and the optional Python package PyMuPDF, then run:

python3 tools/render_figures.py
python3 tools/build_book.py

The full positive endpoint volume theorem

The half-block audit compares the original numerator coefficients, the positive path recurrence, negative roots, exact extreme coefficients, and the finite Lobachevsky formula. Its finite rate profiles remain diagnostics; the uniform closed-domain limit has a written proof.

The earlier shared-source audit checks 228 original coefficients, 4590 support patterns, 748302 affine-cut conditions, 118 one-level support certificates and 236 eventual-flow tests. Those tests remain relevant to fixed half-label patterns. The full-kernel theorem instead uses every degree-N−1N-1 monomial, continuous entropy on the full simplex, and unrestricted integral flow rounding. A separate transfer audit checks 39599 Laurent coefficient comparisons and the path injection used in the central corridor.

The general endpoint theorem proves the geometric upper bound as well. Its structural audit constructs actual Morse faces at widths two, three and four, retains edge identities through genuine identity smoothing, and finds digon disks from the dual graph independently of the Hall subsets. It checks 41 loopless smoothings, 918 hybrid patterns, 121004 Hall cuts, 716 tight sets and 816 independent positive-arc max-flow tests. The general Hall classification, source reduction and volume comparison have separate written proofs.

The signed-chain audit checks 270 signed cyclic fans, four repeated-contact fans, 24 actual circle/line tangencies, eight contact triangles and two oriented strip chains. These validate the volume formulas; the original group pairings, degree-one relative chain and compatible cut-disk collapse are analytical arguments. The serial audit compares 3960 original physical entries, including 1290 illegal-total zeros, and 3120 independent coefficient bounds for literal powers of the same ordered-pair coupon.

The odd regularization audit checks the original spectral derivative and the positive comparison used for the odd coupon VN(−2)−N−2VN′(−2)V_N(-2)-N^{-2}V_N'(-2). The resulting whole-source spectral-jet bound is exact at both parities. These are spectral derivatives at the fixed root, not genuine-qq normals. Recorded replays accompany the formulas; finite fixtures do not establish a selected Gaussian cycle, a complementary phase estimate or the general filled-knot asymptotic.

The full spectral numerator packet

The full packet theorem is an analytical assembly of exact source identities, relative complex cofactor estimates, a global angular gap and the original shared Cauchy coefficient. Its finite tests are scoped to those inputs; samples do not prove the uniform asymptotic or select the later spectral Gaussian contour.

The factorization note compares the central formulas with the original unused-row path polynomial and retains both parity endpoints and the odd central-skipping term. The interior adapter audit checks 1056 row-replaced determinants, 352 independently constructed original q-Hahn matrix node values, 352 sine-product scalars and 960 tail factorizations at 85 digits. The analytic proof separately supplies the exponential interpolation error and discrete saddle estimate for all physical starting rows.

The protected-middle angular audit checks 4636 coefficient bounds, 486 complex angular inequalities, 432 actual three-step matrix entries and 16 exact monomer cases. The marked-action audit compares 24 independent source/cofactor integrals, 17 integral derivatives and 12 literal whole Gauss/collar configurations, together with polarization and Gaussian boundary cancellations. Independent fresh replays reproduce those checks.

The protected-middle relative packet, nodal rigidity, global local-angle theorem and the whole-source assembly have analytical proofs. The finite Cauchy–Lagrange and original face-torus arguments carry the asymptotic conclusions. The direct-power scope retains all fixed-root spectral derivatives while keeping genuine-qq normals separate. Those input audits do not establish global charge dominance or the general filled-knot limit. The later localized contribution is proved by the analytical argument below.

The localized original filling period

The localized unit-charge theorem retains the original marked prefactor, finite-level action, both determinant branches and every boundary term when the integration cube is translated. Its proof gives a nonzero relative Gaussian coefficient at both level parities. The charge comparison, applied to that same finite action, bounds the other charges in a fixed finite local box.

The exact remainder keeps the finitely many selected charges outside the cube and all other charges on their whole original domains; it does not separately sum remote sharp-cube pieces. The proof does not bound this global remainder or establish the general filled-knot volume limit.

Whole-domain bounds and the balanced full invariant

The large-charge audit checks original operator entries, both signed Gaussian exponents, and paired endpoint currents. The diagonal-sector audit includes removable physical nodes, exact path partitions and sewn polynomial integration-by-parts checks. The CROSS audit checks the start decomposition, rescaled transfer matrices and finite characteristic formulas. Their recorded finite checks support the exact formulas. The uniform bounds are established by the written proofs.

The whole-CROSS period, all-angle LEFT envelope, and complete-radius balance theorem prove the stated conditional full-invariant result. Their arguments retain entire-domain remote charge sums and endpoint currents, including both level parities. The elementary entropy lemma checks the absolute half-degree normalization and all protected-zero cases. These arguments prove a full invariant theorem under the stated balance hypothesis. Those conditional arguments alone do not prove realization. The uniform family construction below supplies it, without treating numerical experiments as a proof.

Uniform width and exact bridge number

The family theorem checks the literal incidences, packing reflection, both recurrence branches and endpoints, then proves the required convex comparison. That proof covers every k≥2k\geq2; finite packing samples do not justify its coverage. The zero-middle lemma uses an exact rational lower bound. The Fox certificate proves the signed crossing identity, invariance, exact plat count and bridge bound directly. No numerical asymptotic or coverage audit is claimed for these proofs.

The two focused family audits supplement these proofs: the reduced-source audit checks 38 literal widths and the rational comparison seed; the one-end-source audit checks 39 literal widths, the changed linear boundary, and all circle contacts and noncontacts in the exact width-two and width-three packings. These finite checks do not replace the uniform convex comparison.

Shared-radius certificates beyond complete-packing balance

The anchored theorem retains common-face Cauchy bounds, both parity partitions, a fixed complex strip and the entire Fourier remainder. Its explicit example uses six stated rational vectors. Arb interval arithmetic evaluates finite Lobachevsky sums with an explicit uniform tail bound; exact algebra checks the original golden-ratio packing. The resulting strict inequalities certify this example, not universal coverage of the criterion.

The fixed-triangle capacity lemma is analytical: closed strong concavity gives the explicit squared-distance loss, and finite convex separation proves the shared dual formula even without attained positive multipliers. It does not assert the same comparison for fractional identity mixtures.

A structural extension at arbitrary fixed depth

The unit-chain theorem proves the literal prefix dictionary and an exact extension into the empty marked gap. Its proof preserves every old disk and checks every added crossing-circle block analytically; depth is arbitrary. The focused audit checks 56 original source charts and 12 exact small seed extensions, including 1,084 circle/line support pairs. These finite checks support the source dictionary and geometry, while the proof establishes the unbounded-depth statement.

Simultaneous insertions at every initial bridge gap

The simultaneous theorem has an analytical proof and a finite audit. The audit checks 413 nonuniform-depth source charts, seven exact symbolic transport/ratio identities, and 25 joint small packings with 2,333 support checks. The analytical proof establishes the general source induction, disjoint-gap construction, curvature order and every local block bound. The extended diagram retains its own full normalization; no equality of its framing scalar with the core’s scalar is asserted.

Refined sector covers and a rigorous obstruction

The general finite-cover theorem partitions the source and transfers the entire Fourier remainder using the original shared face targets and both level parities.

The separation verifier checks that both certificates use exactly the same original expression with seventeen crossing-circle blocks and the same mark. An 84-variable rational flow rules out one anchored test by more than 0.0250.025; an 83-variable complete flow and forty rational radius vectors certify the refined cover by more than 0.040.04. All face equations are exact, and Arb evaluations include explicit Fourier-series tails. The public scripts contain no numerical optimizer or private diagnostic inputs.

The undivided positive-capacity obstruction is analytical. Its proof establishes coercivity, rules out escaping level-dependent radii, and distinguishes the bound’s exponential loss from the actual coefficient’s correct volume rate. The proof retains the finite positive-source normalization and the pure-face entropy values.

Uniform coefficient energy and rearrangement

The protected-outer audit constructs the physical coproduct Casimir and extracts coefficients by the original finite Fourier transform. It verifies both parity reference factors and exact spectral sampling nodes. Symbolic identities and fixed integral checks supplement the analytical uniform boundary proof.

The general one-sided audit separately verifies the nonnegative parameter expansion, signed-parameter Cauchy inequalities, interior original coefficients, and the rearrangement identities. The uniform transfer estimate and compact finite-tilt argument are proved analytically, rather than inferred from sampled large levels. The local theorem and its shared-flow consequence have their stated hypotheses; the audit does not establish a stronger global entropy inequality.
