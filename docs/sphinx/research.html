Weighted Conway trees¶

The latest companion theorem fixes any finite rooted ordered tree with at least two vertices. Each vertex carries one integer twist weight. Define nonroot tangles and the root closure by

\[Q_v=T\!\left(R^{n_v}\prod_wQ_w\right),\qquad K=C\!\left(T(R^{n_0})T\!\left(\prod_wQ_w\right)\right).\]

For each fixed tree there is a finite \(B(\mathcal T)\). Every fixed, independently signed weight tuple with \(|n_v|>B(\mathcal T)\) at each vertex and a loop-free one-component terminal pairing satisfies the original invariant’s knot complement volume limit through all levels. The tree and weights are fixed before \(N\) grows. Branching and unary chains are unrestricted. The knot cusp remains unfilled.

This picture specifies tangle syntax, not a knot projection.
