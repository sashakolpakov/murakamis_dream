## 3. A finite compatible subdivision, proved directly

Here is the elementary affine subdivision argument for these cells.
For a three-dimensional convex cell with v vertices, vertex heights
modulo affine functions have dimension v-4. For a paired n-gonal face,
requiring the two height restrictions to differ by an affine function
imposes at most n-3 linear conditions. Under such a condition the two
lower-face subdivisions match, since adding an affine function does
not change a regular subdivision.

For a finite paired affine cellulation, the total remaining dimension
is at least

    sum_cells(v-4)-sum_facepairs(n-3)
                   =(1/2)sum_cells(f-4).                (7)

Use twice the edge count for the sum of face side counts and v-e+f=2
for each convex three-cell. Every cell has f>=4, and equality means
a tetrahedron. If some cell is not tetrahedral, (7) is positive.
Choose a nonzero compatible class of heights and take its lower convex
subdivision. At least one cell refines nontrivially; all new cells are
three-dimensional, use only old vertices and have matched affine faces.
Every original vertex is extreme in projection, so the lower subdivision
does not discard an original boundary vertex.

Repeat. This terminates: assign each resulting three-cell one affine-
independent quadruple of its original vertices. Two cells with disjoint
interiors cannot contain the same nondegenerate tetrahedron. Within
each original cell only finitely many quadruples exist, while every
nontrivial refinement increases the cell count. If a non-tetrahedral
cell remained, (7) would permit another refinement, contradicting this
finite bound. Thus a finite compatible tetrahedral subdivision results.

The edge rows are isotropic: the local skew corner counts cancel
