# Complete selected type-three terminal kernel with type-three incoming leg

Research completion, 6 November 2026.

The selected ordinary-plus-terminal kernel with incoming type three,
ordinary own type four and terminal type three has a uniform raw gap
\(1/10000\) on the whole actual input domain \(K_3\). Its complete
finite source has gap \(1/20000\) at all sufficiently large levels,
of either parity. The incoming leg is unselected. This extends the
last-selection and specified collar assemblies to suffix \((3,4,3)\);
it does not complete the corresponding terminal-type-four case.
