# Notation and conventions

The technical notes were developed over time and sometimes reuse letters. This guide uses the conventions below; each linked proof remains authoritative for its own definitions.

| Symbol | Meaning in this guide |
| --- | --- |
| $N$ | Quantum level; the diagram and filling slopes are fixed before $N\to\infty$ |
| $q=e^{\pi i/N}$ | Principal root used in the displayed symmetric quantum integers |
| $\zeta$ | Generic parameter before root specialization |
| $[r]_\zeta$ | $(\zeta^r-\zeta^{-r})/(\zeta-\zeta^{-1})$ |
| $d=N-1$ | Top physical color index; some notes call it $D$ |
| $j_e$ | Integer spin in the folded scalar theorem |
| $A,B,C,D$ | Integer highest weights in the general four-port theorem; these can represent half-integral spins |
| $E,G$ | Intermediate highest weights for the two four-port pairings |
| $K_N$ | The specified original reduced or marked invariant, with convention stated in its theorem |
| $W_N$ | Positive face-normalized local Racah scalar; not the full knot invariant |
| $Z_{E,N}$ | Whole positive source of the specified Conway expression $E$ |
| $v_3,v_8$ | Volumes of the regular ideal tetrahedron and regular ideal octahedron |

## Three distinctions that matter

**A generic normal versus a level asymptotic.** A derivative in $\zeta=q\exp(t)$ keeps $N$ fixed and differentiates the genuine generic source. It is not the same operation as taking another term in a large-$N$ expansion.

**A source normal versus a zero root value.** A factor such as $[2N]$ vanishes at $q$ but has a nonzero derivative. Removing it before the prescribed normal is taken can change the invariant.

**Complete versus filled volume.** The augmented complement and a complement obtained by Dehn filling generally have different volumes. The filling theorem compares the deformed original source with the actual filled geometry, using its specified peripheral slopes.

The longitude variable $L$ in an A-polynomial, a complete-circle operator called $L_N$, and a recoupling coefficient denoted $L_{G,E}$ are distinct objects. Likewise, a genuine turn and an inverse recoupling matrix can both be called $R$ in older notes. Consult their typed definitions before combining formulas.
