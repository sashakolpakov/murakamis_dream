# Manuscripts and publication preparation

The current collection has 21 subject papers, totaling 420 pages, and a
210-page reference. The 19-page Conway application and its six supporting
papers use the fixed edition `conway-series-2026-11-25`. The reference
shares the Conway proof files and also treats the independent tree and
planar families.

The [manuscript audit](repro/MANUSCRIPT_AND_LOGIC_AUDIT_2026-11-25.md)
records the latest corrections. The
[formal coverage report](repro/PAPER_FORMAL_COVERAGE.md) distinguishes
76 checked statement interfaces from the analytic and geometric
application proofs, which remain written. The
[verification record](repro/results/manuscript-and-lean/verification-summary.json)
links the document, finite-certificate and Lean checks.

The seven-paper Conway collection has prepared source packages and a
[submission plan](repro/HEXAGON_PUBLICATION_PLAN_2026-11-25.md). Preparation
and repository publication do not constitute submission to Hexagon.

Superseded proof copies, historical diagnostic chains and abandoned run
outputs have been removed from the working collection. The pre-cleanup
notes, code and small records are preserved at
[the source snapshot](https://github.com/sashakolpakov/murakamis_dream/tree/19d5b911bc409486f0e72b51a876a6a2bc70ee02).
The snapshot omits bulk generated run dumps. Retained open research is
summarized in the [finite-exception note](notes/research_finite_exceptions_progress.md).
